# AUDIXA

A mobile-first music queue and DJ-style listening interface.

## Current features
- Clean dark interface with antique-gold accents.
- Add public Spotify track URLs and YouTube video URLs.
- Play tracks through official Spotify and YouTube embedded players.
- Browser queue saved locally, with remove and clear controls.
- Responsive layout for phones and desktop.

## Run it
This is a static website. Open `index.html` locally, or enable GitHub Pages:
1. Open repository **Settings**.
2. Open **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.

## Playback notes
AUDIXA does not host, download, or copy music. Spotify and YouTube provide playback through their official embeds. Availability, ads, sign-in requirements, regional restrictions, and embed permissions are controlled by those services. Spotify embeds may show a preview or ask listeners to open Spotify depending on the track and account.

## Roadmap

AUDIXA is an independent project and is not affiliated with Spotify or YouTube.
